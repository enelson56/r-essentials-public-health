3  Basic R Terminology

Let’s learn the language of R

PRACTICAL LEARNING · OPEN SHARING · PUBLIC HEALTH

Learning That Makes a Difference

Learning R is about more than mastering commands: it is about developing tools to ask better questions and make sense of evidence.

NoteLearning objectives

By the end of this lesson, you should be able to:

  1. Create an object and assign a value to it.
  2. Use a function to ask R to do something.
  3. Make a vector using the c() function.
  4. Recognize a data frame and its rows and columns.
  5. Select a column from a data frame using the $ operator.

Before we do any analysis, we need to learn a few basic terms. Don’t worry about memorizing everything today. The goal is to recognize what R is doing and begin writing simple commands on your own.

3.1 Objects and assignment

An object is something you create or store in R. It might contain a number, a word, a vector, an entire dataset, or even a plot.

Use <- or = to assign a value to an object. Both work for basic assignment. We will usually use <- in this class. In RStudio, you can type <- with Alt + - (Windows) or Option + - (Mac).

first_name <- "Erik"
age <- 25

# This also assigns the value 25 to age:
age = 25

first_name
[1] "Erik"
age
[1] 25
TipRead this as…

“Store the word Erik in an object named first_name, and store 25 in an object named age.”

Remember: <- and = are equivalent for these simple assignments. However, == asks whether two values are equal; it does not assign a value.

R is case-sensitive: age and Age are different names. Start object names with a letter, and use underscores instead of spaces.

3.2 Functions: Asking R to do something

A function is a reusable command that performs a task. Functions usually have parentheses (), and you put the information they need inside those parentheses.

class(first_name)
[1] "character"
class(age)
[1] "numeric"
sqrt(25)
[1] 5
TipRead this as…

“Ask R what type of object age is, then ask R for the square root of 25.”

The function is the command (such as sqrt), and the value inside the parentheses is its input. R returns a result.

3.3 Four common data types

Type What it means Example
Numeric Numbers used in calculations 12.5
Character Text in quotation marks "Erik"
Logical True/false values TRUE
Factor Categories or groups, such as species or education level factor(c("Yes", "No")) 
weight <- 178.9
student <- "Jane"
completed <- TRUE

class(weight)
[1] "numeric"
class(student)
[1] "character"
class(completed)
[1] "logical"

Remember:

  • Text needs quotation marks. TRUE and FALSE do not.
  • Factors represent categories. We will explore factors and how to work with them in more detail later in the course.

3.4 R as a calculator

R can do the math you already know: +, -, *, /, parentheses (), and ^ for exponents.

12 + 14
[1] 26
3 * 5
[1] 15
(20 - 4) / 2
[1] 8
7^2
[1] 49

You can also save a result for later.

total <- 12 + 14
total
[1] 26

3.5 Vectors and the combine function c()

A vector is a collection of values stored together. The c() function combines values into one vector. Think of c() as a backpack: it puts several items together in one place.

ages <- c(8, 9, 7, 8)
names <- c("Jackson", "Jared", "Jill", "Jane")

ages
[1] 8 9 7 8
names
[1] "Jackson" "Jared"   "Jill"    "Jane"
TipRead this as…

“Combine four ages and store them in an object named ages.”

A basic vector has one data type. If you mix numbers and text, R may convert the numbers to text.

You can use square brackets [] to retrieve an element by its position. R starts counting at 1, not 0.

ages[2]       # Second age
[1] 9
ages[2:4]     # Second through fourth ages
[1] 9 7 8
length(ages)  # Number of elements
[1] 4

3.6 Simple statistics

Now that we have a numeric vector, we can calculate a few familiar statistics.

mean(ages)
[1] 8
median(ages)
[1] 8
sd(ages)
[1] 0.8164966
min(ages)
[1] 7
max(ages)
[1] 9
summary(ages)
   Min. 1st Qu.  Median    Mean 3rd Qu.    Max. 
   7.00    7.75    8.00    8.00    8.25    9.00
TipRead this as…

“Use the values in ages to calculate the mean, median, standard deviation, and other descriptive statistics.”

summary() gives six values for numeric data: minimum, first quartile, median, mean, third quartile, and maximum. You don’t need to memorize quartiles yet.

3.7 Data frames: Rows and columns

A data frame is a table of data, much like a spreadsheet. Each row usually represents one observation (such as a person or flower), and each column represents a variable (such as age or height).

Let’s use the built-in iris dataset so we don’t need to download anything.

flowers <- iris

dim(flowers)

The iris dataset has 150 rows and 5 columns. You can also click the object in RStudio’s Environment pane to explore it.

3.8 The $ operator: Choosing a column

Usage: dataset$column

3.9 Working with objects

RStudio’s Environment pane shows objects you’ve created. Two useful commands are:

ls()             # List objects
[1] "age"        "ages"       "completed"  "first_name" "flowers"   
[6] "names"      "student"    "total"      "weight"    
rm(total)        # Remove the object named total

You don’t need to remove objects constantly. Just know that you can create, inspect, and remove them.
