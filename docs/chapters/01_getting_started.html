1  Getting Started with R and RStudio

Installing R and RStudio

R BASICS · RSTUDIO · FIRST STEPS

Your Journey Starts Here

Every analysis begins with the right tools. Get R and RStudio ready, explore the workspace, and practice writing and running your first lines of code.

NoteLearning objectives

By the end of this lesson, you should be able to:

  1. Open RStudio and identify its main panes.
  2. Create an R script and run a few lines of code.
  3. Find the Console, Environment, and Help tabs.
  4. Know where to look when you need a little help.

1.1 Introduction

Welcome to R! This document will help you get R and RStudio up and running and show you a few of the basic things we can do in RStudio. You do not need to understand everything today. The goal is to get comfortable opening the program, finding your way around, and running your first lines of code.

One important distinction: R is the program that does the calculations, while RStudio is the place where we write and run our code. If you are installing the programs on your computer, you will need both to officially begin your journey as a useR.

1.2 Installing R and RStudio

If you plan to use RStudio on your own computer, install R first, followed by RStudio.

  1. Install R: Visit CRAN and download the version for your operating system (Windows, macOS, or Linux). Follow the installation prompts.
  2. Install RStudio Desktop: Visit the RStudio download page and download the free desktop version for your operating system.
  3. Open RStudio: Once both programs are installed, open RStudio. You generally won’t need to open R separately.
NoteWhat is a CRAN mirror?

If you are asked to choose a CRAN mirror, it is simply a server from which R is downloaded. Choose a nearby server or the default option. Don’t spend too much time worrying about this!

1.2.1 Alternative: Use RStudio on the Web

You can also use RStudio in your web browser without installing software. This is a useful option if you are on a shared computer or cannot install programs.

  1. Visit Posit Cloud and create an account.
  2. Sign in and create a new project to open RStudio in your browser.
Note

Cloud services may have usage limits or require a paid plan for some activities. For regular coursework, follow your instructor’s guidance on whether to use the desktop or cloud option.

1.3 Finding Your Way Around RStudio

RStudio usually has four main panes. Their locations can be customized, so your screen may look a little different from someone else’s.

Pane What it does Think of it as…
Source (R Script) Where you write and save code Your workspace for writing instructions
Console Where R runs commands and displays results Your conversation with R
Environment Shows objects you have created in the current session Your list of things R remembers
Files / Plots / Packages / Help Lets you browse files, see graphs, manage packages, and get help Your toolbox
ImportantScript versus Console

Write code in a script when you want to keep it. The Console is useful for quickly trying commands, but a saved script is much easier to revisit, fix, and share.

1.3.1 Make Your First R Script

  1. In RStudio, select File > New File > R Script.
  2. Type the code below into your new script.
  3. Place your cursor on a line and press Ctrl + Enter (Windows) or Cmd + Enter (Mac) to run it.
  4. Watch what happens in the Console.
# A little arithmetic
2 + 3
[1] 5
# Save a value in an object
my_number <- 10

# Use that object in a calculation
my_number * 2
[1] 20

Read this as: “Add 2 and 3. Save the number 10 in an object called my_number. Then multiply that saved number by 2.”

Notice that my_number now appears in the Environment. That’s one way to tell R has stored something for you.

TipA quick note about <-

The symbol <- means assign or save as. Read my_number <- 10 as “save 10 as my_number.” We will use this a lot!

1.3.2 Save Your Work

Select File > Save and give your script a useful name, such as my_first_script.R. The .R extension tells your computer that this is an R script.

NoteTry it yourself

Change my_number from 10 to 25, run the two lines again, and check the Console and Environment. What changed?

1.4 Make RStudio Your Own

You can adjust RStudio’s appearance to make it more comfortable to use.

  • Go to Tools > Global Options > Appearance to change the editor theme and font size.
  • Go to Tools > Global Options > Pane Layout if you want to rearrange the panes.

There is no single “correct” appearance. Choose something that makes your code easy to read.

1.5 Where to Find Help

One of the best parts of R is its large, open-source community. There are many free resources available, and you are not expected to memorize every command.

1.5.1 Helpful Learning Resources

  • R for Data Science (2nd edition) — a free book for learning data analysis with R.
  • R Graph Gallery — examples of different types of graphs.
  • Posit Cheatsheets — quick references for common R tasks.
  • RStudio keyboard shortcuts — ways to work more efficiently.

1.5.2 Ask R for Help

You can also ask R directly for help with a function. Try running:

# Open the help page for the mean() function
?mean

Read this as: “Show me R’s help page for the mean() function.” Look for the Help tab in RStudio.
