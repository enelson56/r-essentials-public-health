17  Introduction to Logistic Regression in R

Logistic models

LOGISTIC REGRESSION · ODDS RATIOs · INTERPRETATION

Dealing with binary outcomes in R

Logistic regression helps us describe how a binary (dichotomous) outcome changes with one or more predictors. We will explore the model-building workflow using R datasets, interpret coefficients carefully, and learn how to evaluate model assumptions.

NoteLearning objectives

By the end of this lesson, you should be able to:

  1. Fit and interpret logistic regression models for binary outcomes.
  2. Use gtsummary::tbl_regression() to format regression results for a report.

17.1 Logistic Regression for a Binary Outcome

We will use the infert data. Note that this is a matched case-control dataset, so the ordinary logistic regression we will fit is for demonstration purposes only. We are ignoring the matching in this example.

When the outcome is coded 0/1 or yes/no, logistic regression models the log odds of the outcome. Here case is the binary outcome (1 = case, 0 = control) in the infert dataset.

Let’s peek at the outcome. You want to know the distribution and the reference group of the binary variable.

infert %>% 
  count(case)
  case   n
1    0 165
2    1  83

Let’s fit the logistic model. Here you have to include a few more arguments than a simple linear regression. The family = binomial() argument tells R to fit a logistic regression model. The coefficients are on the log-odds scale. We can exponentiate them exp() to yield odds ratios.

logmodel1 <- glm(case ~ age, data = infert, family = binomial())
summary(logmodel1)

TipRead this as…

glm(..., family = binomial()) fits a logistic regression. Coefficients from summary() are on the log-odds scale. exp(coef(model3)) converts them to odds ratios. An odds ratio above 1 indicates higher modeled odds per unit increase in the predictor; below 1 indicates lower odds. Don’t forget that odds are not the same as probabilities or risk ratios!

TipRead this as…

Each exponentiated coefficient is an adjusted odds ratio comparing observations that differ on that predictor while holding the other included predictors constant. For categorical predictors, the comparison is against the reference category shown in the model output. The confint.default() function provides Wald intervals; these may differ from profile-likelihood intervals produced by confint().

17.3 Present Regression Results with gtsummary

Using summary() and confint() is a bit clunky for reporting results. They are great for quick understanding of model results, but not very useful once you leave R.

The gtsummary package provides a convenient way to format regression results for publication. The tbl_regression() function takes a fitted model object and produces a nicely formatted table of coefficients, standard errors, confidence intervals, and p-values. Complete tutorials are here.

library(gtsummary)

tbl_regression(logmodel1, exponentiate = TRUE) %>%
  modify_header(label = "**Predictor**") %>%
  modify_caption("**Table 1. Logistic regression of infertility on age**")
Table 1. Logistic regression of infertility on age
Predictor OR 95% CI p-value
age 1.00 0.95, 1.05 >0.9
Abbreviations: CI = Confidence Interval, OR = Odds Ratio
