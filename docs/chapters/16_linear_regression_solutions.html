# ============================================================
# LINEAR REGRESSION: SOLUTIONS
# Work through the tasks in order in your R Project.
# Use the Boston dataset from the MASS package.
# ============================================================

# SETUP ------------------------------------------------------

library(tidyverse)
library(MASS)
library(gtsummary)

# Load the Boston dataset
data(Boston)

# Outcome: medv (median home value, in $1,000s)
# Predictors:
# nox     = Nitric oxides concentration
# crim    = Per capita crime rate
# rm      = Average number of rooms per dwelling
# ptratio = Pupil-teacher ratio


# PART 1: VISUALIZATION AND CORRELATION -----------------------

# TASK 1: Using ggplot2, create a scatterplot examining the
# relationship between nox and medv. Add a fitted linear
# regression line using geom_smooth(method = "lm").
# Include appropriate labels and theme_classic().

ggplot(Boston, aes(x = nox, y = medv)) +
  geom_point() +
  geom_smooth(method = "lm", se = FALSE, color = "blue") +
  labs(title = "Scatterplot of NOx vs. MEDV",
       x = "Nitric Oxides Concentration (nox)",
       y = "Median Home Value (medv)") +
  theme_classic()
# TASK 2: Fit a preliminary linear regression model predicting
# medv from nox. Extract the residuals and create a Q-Q plot.
# Do the residuals appear approximately normally distributed?

model1 <- lm(medv ~ nox, data = Boston)


model_diagnostics <- tibble(
  fitted = fitted(model1),
  residual = resid(model1))

# Residuals vs Fitted Plot
ggplot(model_diagnostics, aes(x = fitted, y = residual)) +
  geom_point(color = "#167C80", alpha = 0.75) +
  geom_hline(yintercept = 0, linetype = "dashed", color = "grey40") +
  labs(title = "Residuals Versus Fitted Values", x = "Fitted Nitric Oxides Concentration", y = "Residual") +
  theme_classic(base_size = 15)

Normally Distributed? Yes, roughly. The points are scattered around the horizontal line at 0, and there are no obvious patterns or trends in the residuals. However, there are a few outliers that may affect the normality of the residuals. Good to proceed to linear regression.

# TASK 3: Use cor.test() to calculate the Pearson correlation
# between nox and medv. Report the correlation coefficient
# and p-value. Is the relationship positive or negative?

cor(Boston$nox, Boston$medv)

# PART 2: SIMPLE LINEAR REGRESSION ----------------------------

# TASK 4: Use lm() to fit a simple linear regression model
# predicting medv from nox. Save the model as model_1.
# Use summary() to examine the results.
# Interpret the regression coefficient for nox.

model_1 <- lm(medv ~ nox, data = Boston)
summary(model_1)

# PART 3: MULTIPLE LINEAR REGRESSION --------------------------

# TASK 5: Fit a multiple linear regression model predicting
# medv from nox, crim, rm, and ptratio.
# Save the model as model_2 and display summary().
# Compare the coefficient for nox between model_1 and model_2.
# Does the association change after adjustment?

model_2 <- lm(medv ~ nox + crim + rm + ptratio, data = Boston)
summary(model_2)

Coefficient Comparison: In model_1, the coefficient for nox is -34.67, while in model_2, the coefficient for nox is -17.77. The association between nox and medv becomes less negative after adjusting for other predictors (crim, rm, and ptratio). This suggests that some of the variation in medv that was attributed to nox in the simple model is now being explained by the additional predictors in the multiple regression model.

Association: The association between nox and medv is still negative, but it is weaker in the multiple regression model compared to the simple regression model. This indicates that other factors (crim, rm, and ptratio) also play a role in predicting median home value, and the effect of nox is partially confounded by these variables.

# PART 4: PRESENTING REGRESSION RESULTS -----------------------

# TASK 7: Use gtsummary::tbl_regression() to present model_2
# in a formatted table. Include regression coefficients,
# and p-values.
# Use bold_p() to highlight statistically significant results.

library(gtsummary)
tbl_regression(model_2) %>%
  bold_p(t = 0.05) %>%
  modify_header(label = "**Predictor**") %>%

# REFLECTION -------------------------------------------------
# What is the difference between simple and multiple linear
# regression? Why might the coefficient for nox change after
# adding additional predictors to the model?
# Write your answer as a comment below.

The difference between simple and multiple linear regression is that simple linear regression examines the relationship between one predictor variable and the outcome variable, while multiple linear regression examines the relationship between multiple predictor variables and the outcome variable simultaneously.
