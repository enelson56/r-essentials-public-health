4  R Packages

Take advantage of these gifts

INSTALL · LOAD · EXPLORE

Give R New Superpowers

R packages add useful tools without requiring you to build everything from scratch. Practice the difference between installing and loading packages, and explore how to use a package function and built-in data.

NoteLearning objectives

By the end of this lesson, you should be able to:

  1. Install and load an R package.
  2. Use a function from a package
  3. Explore a built-in dataset in R.

4.1 What are R packages?

One of the beautiful things about R is that we get to use the coding genius of other people! An R package is a collection of functions, data, and documentation that someone has created and shared with others.

Think of packages as gifts. Someone else has done the hard work of putting something useful together, but we still have to open the gift to use it.

4.2 The 2-step routine

To use most packages, there are two steps:

  1. Install the package on your computer. Usually, you only need to do this once per computer (unless you need to update or reinstall it).
  2. Load the package when you start a new R session and want to use its functions.
Action R command When?
Install install.packages("psych") Usually once per computer
Load library(psych) Each new R session when needed
TipRead this as…

Install: “Download the psych package so my computer has it.”

Load: “Make the functions in psych available for me to use in this R session.”

4.2.1 Step 1: Install a package

Let’s try the psych package. It includes helpful functions for describing data.

In RStudio, you can go to the Packages tab and select Install, then type psych. Or you can run this command in the Console:

install.packages("psych")

You should see messages in the Console while R downloads and installs the package. If the installation finishes successfully, you are ready for Step 2.

NoteA habit worth developing

Keep installation commands separate from the code you run every day. Once a package is installed, you don’t need to reinstall it each time you open RStudio.

4.2.2 Step 2: Load a package

Now let’s go to the library and check out our package!

In RStudio, you can check the box beside an installed package in the Packages tab. More commonly, we’ll load packages with code:

library(psych)
TipRead this as…

“Go to my collection of installed packages and load psych so I can use its functions.”

Think of install.packages() as adding a book to your own collection. library() is taking that book off the shelf to use during your current R session. When you close R, the package remains installed; you just need to load it again next time.

4.3 Let’s use the psych package

We’ll use the built-in mtcars dataset. You don’t need to download a separate data file for this example.

# View the first six observations
head(mtcars)

# Find the average miles per gallon (base R)
mean(mtcars$mpg)

Now suppose we want several descriptive statistics at once. Instead of writing many separate commands, we can use describe() from psych.

library(psych)

# Describe one variable
describe(mtcars$mpg)

# Describe all numeric variables in the dataset
describe(mtcars)
TipRead this as…

“Use the describe() function from the psych package to summarize miles per gallon (or the entire dataset).”

Notice that one function gives us several useful statistics, including the mean, standard deviation, minimum, and maximum. This is why packages are so helpful: other people have already built tools that make our work easier.

4.3.1 What does :: mean?

Look at this line, which is nearly identical to the one above:

psych::describe(mtcars$mpg)

The :: tells R exactly which package contains the function we want. It also lets us use that function without first calling library(psych).

TipRead this as…

“From the psych package, use the describe function on the mpg variable in mtcars.”

Both approaches are useful:

# Option 1: Load the package, then use the function
library(psych)
describe(mtcars$mpg)

# Option 2: Call the function directly from its package
psych::describe(mtcars$mpg)

For now, you should recognize both forms. We’ll primarily use option 1, but there may be times you see help sites (or AI) use :: so I want to be aware of it.

4.4 The big takeaway

Install once. Load when needed. Use the functions. That’s the routine I want you to remember.

As we learn more R, you’ll encounter many packages. Don’t worry about memorizing all their names. Focus on recognizing what a package does, how to load it, and how to find and use its functions.
